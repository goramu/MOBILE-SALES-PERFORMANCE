# MOBILE-SALES-PERFORMANCE

An interactive **Power BI dashboard** developed to analyze mobile sales performance and provide actionable business insights. The dashboard enables users to explore sales trends, product performance, customer behavior, and regional performance through interactive visualizations and filters.

## Key Features

* Analyzed overall mobile sales and revenue performance.
* Tracked sales trends across different time periods.
* Compared performance by mobile brand, model, and category.
* Analyzed sales by city/region and payment methods.
* Created interactive KPIs, charts, slicers, and filters.
* Identified top-performing products and key sales patterns.
* Designed an interactive and user-friendly dashboard for business reporting.

## Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Cleaning & Transformation**
* **Data Visualization**

## Project Objective

To transform raw mobile sales data into an interactive business intelligence dashboard that helps users monitor sales performance, identify trends, and derive meaningful insights for data-driven decision-making.
